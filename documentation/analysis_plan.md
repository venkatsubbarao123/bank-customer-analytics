# Analysis Plan

## Objectives

- Understand the shape and quality of the transaction data.
- Produce a consistent cleaned dataset for analysis.
- Identify customer, location, time, and transaction-value patterns.
- Prepare metrics that can be reused in SQL and Power BI.

## Core metrics

- Transaction count
- Total transaction amount in INR
- Average transaction amount in INR
- Unique customers
- Average account balance
- Transactions by date, location, and gender

## Data-quality checks

- Duplicate transaction IDs
- Missing customer or transaction identifiers
- Invalid dates and times
- Negative or missing transaction amounts
- Unexpected gender or location values
- Outliers in transaction amount and account balance
